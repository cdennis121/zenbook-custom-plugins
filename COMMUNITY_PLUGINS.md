# Community plugins

Official plugins ship in this repo under [`plugins/`](./plugins/).

Community plugins are listed here. **Install** by cloning or copying the plugin folder into your local `plugins/` directory, then click **Reload** (or restart the host).

## Submit a plugin

1. Build against the [Plugin API](./docs/plugin-api.md) (use `plugins/_template`).
2. Publish your own git repo **or** open a PR adding `plugins/<id>/` here.
3. Add a row to this table (name, match targets, author, link, short notes).

Keep plugins free of personal absolute paths and secrets.
